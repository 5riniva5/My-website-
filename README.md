# My-website

Welcome to the repository for my personal website! This project is a custom multi-tab site built from scratch to showcase my work, interests, and learning journey in front-end development.

## Overview
* **Design & Theme:** A high-contrast dark aesthetic featuring a pure black background, clean white text, and striking fire-red accents.
* **Tech Stack:** Built using vanilla HTML5, CSS3, and lightweight JavaScript to manage seamless client-side tab switching without page reloads.
* **Layout & Structure:** Responsive grid systems for projects, a sticky navigation bar, smooth tab-switching animations, and a custom-styled scrollbar.

## Sections & Features
* **Home:** Serves as the main landing tab with an introduction to who I am and my journey learning web development.
* **Projects:** Highlights key builds, including **EterniaOS** (a browser-based desktop operating system interface) and layouts designed for educational youth science workshops.
* **Hobbies:** Details my interests in coding experimental mini-applications, keeping indoor plants healthy, and tinkering with developer tools and Git workflows.
* **Contact:** Provides a direct link to connect and view my source code repositories on GitHub.

## Getting Started Locally
To run or preview this project on your local machine:
1. Clone this repository to your computer or open it directly in a workspace environment like GitHub Codespaces.
2. Open the `index.html` file in any modern web browser or use a live server extension to view the site.
